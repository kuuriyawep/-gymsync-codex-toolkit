## Findings

For each finding, use this structure:

### [Critical | High | Medium | Low] Short finding title
- **Status:** confirmed defect | likely defect | question | informational
- **Location:** exact file and line / symbol
- **Scenario:** concrete conditions that trigger the issue
- **Evidence:** observed code, test, command output, or reproducible trace
- **Impact:** correctness, security, data, performance, or maintainability consequence
- **Recommended remediation:** smallest actionable correction
- **Verification:** safe test or evidence that would confirm the fix

If there are no findings, explicitly state that no findings were identified within the reviewed scope; do not imply the entire repository is defect-free.
