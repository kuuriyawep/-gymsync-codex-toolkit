# Decision records

Create one Markdown file per durable technical or product decision. Use stable identifiers and preserve history. Do not overwrite a decision when it is superseded; update its status and link the replacement.

Suggested filename: `YYYY-MM-DD-short-decision-title.md`.

Each record should include:
- ID and title
- Status: Proposed, Accepted, Rejected, Superseded, or Deprecated
- Date and decision owner
- Context and problem
- Options considered
- Decision and rationale
- Consequences and risks
- Evidence/source references
- Approval record, when required
