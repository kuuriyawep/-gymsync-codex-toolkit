# Release Readiness
1. Confirm release scope and acceptance criteria.
2. Inspect diff, configuration, migrations, dependencies, and secrets.
3. Run tests, build, type checks, lint, and relevant security checks.
4. Verify critical user journeys and permission boundaries.
5. Confirm rollback and operational observability.
6. List blockers, accepted risks, and skipped checks.
7. Ask for approval before deployment or irreversible remote actions.
8. Report readiness as ready, conditionally ready, or blocked with evidence.
