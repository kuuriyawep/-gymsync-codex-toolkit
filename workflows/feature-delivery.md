# Feature Delivery
1. Explore existing UX, architecture, conventions, and related data flows.
2. Clarify user roles, use cases, non-goals, and acceptance criteria.
3. Map impact across frontend, backend, database, auth, and tests.
4. Plan incremental tasks, migration compatibility, and release sequence.
5. Obtain approval for the plan and any risky side effects.
6. Implement in small vertical slices; preserve established design.
7. Test happy paths, validation, permissions, and failure states.
8. Review independently; verify against acceptance criteria.
9. Update docs and provide a factual delivery summary.
