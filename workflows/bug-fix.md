# Bug Investigation and Fix
1. Explore: reproduce safely and collect evidence.
2. Clarify: confirm expected behavior and acceptance criteria.
3. Impact: trace affected paths, data, roles, and integrations.
4. Plan: state root-cause hypothesis, minimal fix, tests, and rollback.
5. Approval: obtain approval if scope, data, or production risk changes.
6. Implement: add regression test and make the smallest fix.
7. Review: independent code and security review for sensitive paths.
8. Verify: run targeted and relevant broader checks.
9. Document: report cause, change, checks, and remaining risk.
