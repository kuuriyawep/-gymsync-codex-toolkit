# Learning System

Use this directory to capture reusable lessons from real work without allowing uncontrolled self-modification.

## Inbox
Place a proposed lesson in `inbox/` with:
- Context and observed problem
- Evidence (file paths, test output, or reproducible case)
- Proposed reusable lesson
- Scope and known limitations
- Source/provenance if derived externally

## Approval
Review for accuracy, generality, duplication, safety, and compatibility. Only approved lessons move to `approved/`.

## Rules
- Never store secrets, personal data, or project-specific credentials.
- Do not promote speculation or one-off guesses.
- Do not automatically edit AGENTS.md or skills from an agent's own output.
- Keep lessons short and actionable; link to project documentation rather than copying it.
