# Source Attribution and Adaptation Register

This toolkit draws on ideas and public documentation from:
- [ECC](https://github.com/affaan-m/ECC) — verification loops, security review, TDD, change-impact analysis.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) — skill metadata and workflow orchestration patterns.
- [Matt Pocock Skills](https://github.com/mattpocock/skills) — debugging, code review, TDD, and requirements shaping.
- [Superpowers](https://github.com/obra/superpowers) — brainstorming, systematic debugging, planning, and verification gates.
- [OpenCode](https://github.com/anomalyco/opencode) — separation of read-only exploration/planning and implementation permissions.
- [Anthropic Skills](https://github.com/anthropics/skills) — skill authoring and evaluation methodology.
- [Caveman](https://github.com/JuliusBrussee/caveman) — clarity-first communication and concise review reporting.

This register records conceptual influence, not permission to copy files. Exact per-file licenses must be checked before any verbatim reuse. Graphify is intentionally excluded. Caveman's destructive file-compression behavior is excluded.
