# Skill Authoring and Evaluation
1. Define the task, intended user, trigger phrases, and non-goals.
2. Write a concise description and a stepwise procedure.
3. State prerequisites, safety boundaries, expected output, and failure handling.
4. Test with representative prompts, edge cases, and out-of-scope prompts.
5. Check whether the skill triggers appropriately and whether instructions are executable.
6. Revise based on observed failures; preserve test cases as evals.
Avoid tool-specific commands unless the target environment supports them. Never claim evaluation without running it.
