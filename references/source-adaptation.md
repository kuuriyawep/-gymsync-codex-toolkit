# Source Adaptation Policy
This toolkit is an original Codex-first curation informed by public repositories; it is not a wholesale mirror.
- Prefer independently written procedures and general workflow ideas over copying source text.
- Before verbatim reuse, verify the exact license and applicable NOTICE/attribution requirements for that specific file.
- Preserve copyright and license notices when required.
- Record source URL, license, inspected artifact, adaptation summary, and date in the attribution register.
- Do not assume a repository-wide license covers every vendored or third-party asset.
- Exclude platform-specific hooks, commands, agents, and runtime dependencies unless verified compatible with Codex.
- Never copy secrets, generated credentials, or private user data.
